# Matrice de couverture

Légende :
- **V** = implémenté et vérifié par des tests automatisés exécutés ici : unitaires, plus parcours réels dans Chrome sur les 9 services ;
- **D** = mode démonstration ;
- **C** = nécessite une configuration externe ;
- **R** = restant à réaliser.

Sources des vérifications : `bin/test` (tests de chaque projet, plus `cargo test` du moteur natif), les parcours
de `e2e/` dans Chrome, `backend_smoke` et `privacy_smoke` entre services, et `responsive` de 320 à 1440 px en
anglais et en français.
